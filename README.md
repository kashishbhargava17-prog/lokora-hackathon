LOKORA — Legacy Of Knowledge, Oral Records & Ancestry

Theme: Heritage and Culture
Hackathon Topic: Interactive Language and Folk Knowledge

LOKORA is a static front-end prototype designed to preserve and digitize India's endangered oral heritage, regional languages, dialects and folk knowledge.

The platform acts as a bridge between knowledge holders such as elders, storytellers and local experts, and knowledge seekers such as students and young learners.

Problem Statement

«To build a scalable and user-friendly platform that acts as a bridge between knowledge holders (elders) and knowledge seekers (youth) to preserve and digitize India's endangered oral heritage and folk knowledge.»

Our Solution

LOKORA creates an interactive digital space where cultural knowledge can be discovered, learned, shared, reviewed and preserved.

The platform focuses on:

- Regional language and dialect content
- Folk stories
- Proverbs and idioms
- Traditional songs
- Local vocabulary
- Oral-history content
- Pronunciation recordings
- Cultural context
- Interactive lessons
- Games and quizzes
- Story-based learning
- Community contributions
- Expert validation
- Multilingual support
- Progress tracking
- Search and discovery
- Educational content creation

The project can be deployed using GitHub Pages.

1. Create a public GitHub repository.
2. Upload the project files.
3. Open Settings → Pages.
4. Select GitHub Actions or the appropriate branch publishing option.
5. Deploy the project.

Cultural Responsibility

The cultural records currently included in this prototype are demo/prototype records.

A real deployment should use:

- Consent from knowledge holders
- Community participation
- Accurate documentation
- Cultural-context preservation
- Expert/community validation
- Responsible handling of recordings and personal information

LOKORA aims to support preservation with communities, not simply about communities.
